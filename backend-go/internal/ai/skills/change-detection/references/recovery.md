# 异常处理

- UI_CONTEXT_STALE：回执中的 workspace 和 context_revision 是最新状态。核对用户条件仍成立后，用新版本修正一次；不得重复旧版本调用。
- WORKSPACE_BUSY：已有检测或正在编辑，读取工作区任务引用并告知进度，不再提交。
- DETECTION_SUBMIT_FAILED：根据具体原因澄清。日期不存在或不足两时相时请用户选择可用月份；无框选时请绘制；模型或配置未就绪时说明管理页需要完成的步骤。不能擅自换日期、范围或模型。
- 回执超时或连接中断：任务可能已经提交。先查看 workspace 的 task_id，不能再次执行 submit_detection 试错。
- 连续范围默认首尾；明确的月份列表只使用该列表。日期精度为月时不编造日。相对日期须先查询目录后确认实际月份。
- 指定逐月比较但目录缺月份时，请用户确认可用时相，不补造影像。
- MultiPolygon 不能直接作为本工作区单个 Polygon 框选，需用户选择有效独立区域。
- 当前模型输出变化掩膜和分数，不能分类建筑、道路或确认违法占地。

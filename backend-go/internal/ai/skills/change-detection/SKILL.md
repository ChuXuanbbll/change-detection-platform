# 变化检测

用户明确要求执行或新建检测时使用。先读 `workspace.context`；当前区域、AOI、时相和算法配置有效时直接调用 `ui.submit_detection`。该命令与页面“开始检测”共用业务入口，自动解析本次明确指定的时相，保留当前框选与参数，并返回已创建的任务引用。

- 两个明确月份使用 `phase_dates`，例如 `["2025-03", "2025-09"]`；不得展开为区间内所有月份。普通日期范围默认首尾比较；仅明确要求逐时相比较时使用 adjacent。
- 已有区域无需重新选择，已有 AOI 无需重新设置。无需为检测飞行地图、创建计划、裁切编排或轮询准备状态。
- 缺区域时先查 `region.search`，唯一匹配后才 `ui.select_region`；无有效 AOI 或时相不明确时调用 `request_clarification`。
- 用户给了参数时将明确数值保留在 detection_settings 槽位；未指定的值沿用工作区。模型变更须使用已验证 ID。
- 成功回执只表示已提交检测，不能宣称推理已完成。批次进度由工作区持续跟踪；不要重复提交，也不要在本轮反复轮询。

仅在命令失败、日期覆盖不足或用户询问限制时，通过 `skill.read_reference` 读取 [异常处理](references/recovery.md)。

# 本地与共享目录影像

按 2026-10-12 的影像索引、裁切和拼接实现核对。本文为当前检测输入规则；行政区和兼容显示源见 [接入说明](imagery-integration.md)。

影像来源通过第四页「管理 → 影像来源」登记。首次从 `LOCAL_IMAGERY_DIR` 迁移（未设置时沿用 `Y:\河北影像\2025年`），后续以数据库生效版本为准。运行账号必须能读取本地或 UNC 路径。

普通目录采用 `年份根目录 / 行政区名称 / 月份目录 / *.tif`，例如 `2025年/石家庄市/3月/a.tif`。根目录名称不包含年份时，在来源配置中显式填写年份。月份只按目录解析；同月重复拍摄不会从文件名推断成多个时相。旧项目 `catalog.json` 保持迁移兼容。

影像至少三个 uint8 RGB 波段并具有 CRS。目录扫描读取元数据，缓存写入运行数据目录，不向共享盘写辅助文件。单文件损坏显示不可用与原因；整个启用来源不可访问时拒绝发布新配置。

多个来源按稳定来源 ID 与相对路径形成影像身份。同区域同月份合并展示和计算：真实分辨率优先，有效像元缺失由下一来源补齐；同分辨率按管理页来源顺序、相对路径排序。检测与瓦片共用拼接逻辑，不把黑色有效像元误判成空洞。输入范围采用 WGS84 `[west,south,east,north]`，真实河北边界裁切，地图边界来自 `data/boundaries`。

来源变化会失效旧合成版本；运行中的工作区批次结束后更新选择。删除来源仅修改配置，不删除原始 TIFF。批次裁切影像写到 `DATA_DIR/shared/<batch_id>`，独立于来源后续变化。

不限制框选像元数。推理、后处理和矢量化仍受真实显存、内存与磁盘限制；错误如实返回，不自动降精度或静默换模型。详细模型、版本和运行配置见 [管理说明](MANAGEMENT.md)。

## 快速拖动与瓦片队列

瓦片请求直接传递 ASGI 断开信号，避免通用 HTTP 中间件包装接收通道后丢失浏览器取消。离开视野的等待任务会退出队列；已经进入 GDAL 的任务继续占用原渲染槽直至完成，防止实际进程并发失控。短暂满队列在同一等待预算内接纳新视野请求，真正超时或超过请求上限才返回 503。

默认等待时间为 1000 毫秒。**已持久化配置不会被默认值覆盖**：若仍为旧的 25 毫秒且快速拖动经常触发队列超时，可在「管理 → 后端瓦片」调整为 1000 毫秒再应用，其他参数按实际负载决定。工作进程按来源路径、文件版本缓存路径校验，目录刷新、版本变化和进程关闭会失效，避免每张瓦片重复访问 SMB 解析路径。

`backend-py/.venv-local/Scripts/python.exe -X utf8 scripts/benchmark_tile_pan.py --baseline 76b3d8c` 从运行服务只读获取雄安影像快照，在独立端口对照指定提交与工作区代码。它模拟连续取消四组请求，再以四请求并发加载最终视野的 24 张瓦片；两侧使用各自默认队列参数。报告写入 `data/validation/tile-pan-*/report.json`，不更改工作服务的配置、数据库或原始影像。该固定范围基准需要已有雄安影像，用于网络/渲染对照，不替代实际浏览器视觉验收。

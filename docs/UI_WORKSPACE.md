# 四页工作区

按 2026-10-12 代码核对。四页共享当前浏览器工作区，管理操作见 [管理与配置](MANAGEMENT.md)。概览右栏选择经过验证的模型和本批次参数；检测完成后预览异步加载，不阻塞下一组。

## 检测工作区

前端使用持久应用外壳与 Vue Router：`/overview`（概览）、`/comparison`（对比）、`/reports`（报告）、`/management`（管理）。根路径和未知路径跳转至概览。界面为深色单主题。

## 工作流

- 概览保留本地地图、覆盖限制、区域框选、多边形绘制、顶点与边编辑、坐标输入和图层控制；操作面板移至右侧。运行期间禁止修改区域，地图仍可平移和缩放。
- 从区域目录添加至少两个可用月份时相，按时间顺序检测已选时相的相邻组；没有自动把整个目录纳入检测。应用外壳拥有任务轮询和结果缓存，切换页面、调整窗口宽度不会重启批次。
- 第一组完成后默认选中该组，后续完成不改变用户选择。某组失败时停止后续检测，保留先前完成结果。
- 对比展示选中时相组的前、后影像及前影像上的不透明变化掩膜。三图联动；点击按面积降序排列的前十个热点可共同定位。
- 报告列出本批次各组状态、指标、完整图斑列表（每页 25 个）和 GeoTIFF、GeoJSON、CSV、Shapefile ZIP 导出。
- 当前批次仅保存在页面会话内。刷新或关闭页面不会自动恢复批次；后端已生成的任务产物不受影响。

## 数据口径与接口兼容

选择行政区后，在「地图工具」中点击「多边形区域」，单击加点，点击起点、双击或 Enter 完成；Backspace 撤销上一点，Esc 取消。首点须位于当前行政区内；后续点沿上一顶点到鼠标的连线吸附到首次出界处。凹陷、孔洞或离散区域导致闭合越界时，需要补点或调整，整个选区必须位于行政区内。

完成绘制后直接显示顶点、边和加点手柄，无需进入编辑模式或点击完成编辑。拖动顶点调整位置；拖动边平行移动，端点与相邻边延长线求交；点击边中点添加顶点，选中顶点后 Delete 删除，至少保留三个顶点。每次合法拖动在松开鼠标后自动保存，加点和删除立即保存；拖动中按 Esc 或收到 pointercancel 撤销本次拖动，保留已保存选区。编辑时同时检查两条相邻边及内部区域，非法位置不提交。仅绘制和实际拖动期间禁止提交检测，停止操作即可提交。框选、应用手动经纬度替换为矩形，清除或切换行政区清除整个选区。

框选矩形同样在画完后直接编辑顶点和边，修改后以多边形提交。沿边方向的拖动不改变边；相邻边共线、端点折返、退化、自交或越界时保留上一次合法位置。顶点和加点手柄显示在边的点击区域上方，互不遮挡；小选区可以放大后操作。空白地图拖动平移、滚轮及双击缩放均可使用，缩小地图不会清除已有选区。部分越过行政区的矩形先按行政区边界裁切以展示可编辑的实际范围，第一次修改时保存为多边形；交集为空、包含孔洞或多个离散区域时提示重新选区，原矩形仍可按原规则检测。

像元标签显示「矩形裁切网格」尺寸，右侧多边形信息显示包围盒及顶点数。当前不提供孔洞绘制或多个独立选区。接口和掩膜约定见 [API](API.md#多边形选区)。

面积、图斑数、变化比例和置信度均沿用结果字段。变化比例以共同有效像元为分母；平均变化置信度为最终变化掩膜覆盖像元的模型得分均值，不是准确率。无变化时该均值显示 `—`。图斑按已有八邻域连通定义统计，面积沿用已有等面积投影计算。

置信度分布通过现有 `stats_json` 的可选字段 `confidence_histograms` 提供：

```json
{
  "bin_edges": [0.0, 0.05, 0.1],
  "changed_counts": [0, 0],
  "all_valid_counts": [0, 0],
  "changed_sample_count": 0,
  "all_valid_sample_count": 0
}
```

示例仅省略展示后续桶；实际固定为 21 个边界（0 至 1，步长 0.05）、每种分布 20 个计数，最后一桶包含 1。计算前已应用共同有效掩膜，排除非有限和超出 `[0,1]` 的得分；零是有效得分。均值计算也排除非有限值，避免无效 JSON。老结果缺少此字段时显示“置信度分布不可用”，不反推或伪造分布。

旧影像元数据及旧结果保持兼容，不回填旧结果。更新代码后服务须加载对应版本；旧进程不会因文档更新自动支持多边形协议。

多边形在推理前裁切并写入有效掩膜，推理及后处理结束后再使用共同有效掩膜限制结果、矢量化及统计；透明预览排除区域外像元，地图结果轮廓沿提交时的多边形显示。Go 要求 Python 确认 AOI，前端检查裁切影像元数据；旧服务遗漏多边形时停止批次并提示重启，防止按外接矩形继续检测。

## 预览限制

复用现有 `/py/overlay/image` 与 `/py/overlay/mask`。对比请求影像最长边 2048，现有掩膜接口仍限制为 512；地图缩放不增加预览分辨率，原始精度使用 GeoTIFF 导出。热点缩略图在浏览器裁剪预览并绘制图斑轮廓。

同一对比组的预览必须使用一致的受支持坐标系（EPSG:4326 或 EPSG:3857）。对于其他坐标系或不一致的预览明确提示，不在前端猜测投影。
